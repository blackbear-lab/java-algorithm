# Java Algorithm

paizaを中心に、Javaによるアルゴリズムとコーディングテスト対策に取り組むための学習リポジトリです。

## 学習目的
- Javaによる問題解決能力の向上
- アルゴリズムとデータ構造への理解の深化
- 時間計算量・空間計算量を意識した実装力の向上

## 学習環境
- Java (JDK 26)
- IntelliJ IDEA
- [paiza](https://paiza.jp/)

## 学習方針
1. paizaの練習問題やスキルチェックを通じて、自力で解法を考える。
2. 実装後に計算量やコードの可読性、改善点を振り返る。
3. 学習したアルゴリズムやデータ構造を、自作の例題などで復習する。
4. 学習内容を日本語でSTUDY_NOTES.mdに整理する。

## 公開方針
本リポジトリには、公開が許可されている練習問題の実装、自作の例題、一般的なアルゴリズムの実装および学習記録を掲載します。paizaのスキルチェックの問題文・解答コード・解法など、公開が禁止されている情報は掲載しません。

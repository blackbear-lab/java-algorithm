# Java Algorithm

Javaを用いたアルゴリズムとコーディングテストの学習記録です。

## 学習環境
- Java (JDK 26)
- IntelliJ IDEA

## ディレクトリ構成
| ディレクトリ | 内容 |
|---|---|
| src/atcoder | 公開可能なAtCoderの問題演習 |
| src/sorting | ソート |
| src/searching | 探索 |
| src/datastructure | データ構造 |
| src/dp | 動的計画法 |
| src/practice | 自作・公開可能な練習問題 |

## 学習方針
- 自力で解法を考え、実装する。
- 時間・空間計算量と改善点を整理する。
- 公開が禁止されている問題や提出コードは掲載しない。
